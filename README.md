# Hospital Management System (HMS)

A comprehensive web-based Hospital Management System built to streamline healthcare administrative operations, doctor-patient coordination, and secure data handling.

## 🚀 Tech Stack
* **Backend:** ASP.NET Core 8.0, C#, Entity Framework Core
* **Database:** Microsoft SQL Server
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla), Bootstrap
* **Authentication:** JWT (JSON Web Tokens) & Role-Based Access Control (RBAC)

## 📌 Features
* **Role-Based Access Control:** Secure permissions for administrators, doctors, and staff members.
* **Patient & Staff Management:** Efficient handling of departmental structures, staff rosters, and patient records.
* **Appointment Scheduling:** Streamlined booking and status tracking for medical appointments.
* **Database Security & Resilience:** Robust foreign-key constraints, server-side validation, and connection resiliency using EF Core.
